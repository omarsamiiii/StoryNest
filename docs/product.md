# Product Notes

StoryNest helps parents turn small family preferences into calm bedtime stories. The paying user is the parent, and the child is never treated as an account holder or direct chat participant.

## MVP Jobs

- Create parent account.
- Add nickname-based child profiles.
- Generate structured bedtime stories.
- Save and browse a private story library.
- Generate printable coloring page ideas.
- Understand plan limits before upgrading.

## Safety Positioning

StoryNest deliberately avoids public profiles, public feeds, direct child chat, and child uploads in the MVP. Personalization uses a nickname, age range, interests, tone, and parent instructions.
